Calculator Pro 3.0 🧮

A simple and elegant calculator application built with Flutter.

📌 About

Calculator Pro is a Flutter-based calculator application designed with a clean and user-friendly interface. It supports basic mathematical operations and stores calculation history locally.

✨ Features

- Basic arithmetic operations (+, -, ×, ÷).
- Percentage calculations.
- Decimal number support.
- Clear and delete functions.
- Calculation history.
- Delete individual history records.
- Local data persistence using SharedPreferences.
- Dark user interface.

🛠️ Built With

- Flutter
- Dart
- Material Design
- SharedPreferences

🚀 Getting Started

1. Clone this repository.
2. Install the dependencies:

flutter pub get

3. Run the application:

flutter run
